Type here is mostly working type — dense application UI rather than reading
material. So the default is `text-sm`, not `text-base`, and the scale goes
down from there before it goes up. Reach for `xs` or `2xs` when a surface
needs to hold more.

## Typeface

Inter, a workhorse typeface drawn specifically for interfaces. It's
self-hosted as a variable font across the full 100–900 weight axis, so any
weight costs the same as any other.

`2xs` isn't a Tailwind size — it's defined in `global.css` as a 10px rung
below `xs`, with a 14px line height to match the shape of the built-in sizes.

## Weight

Headings are `font-extrabold`. Where headings nest and need separating, or
where a heading should sit back rather than announce itself, drop to
`font-semibold`.

<Card class="not-prose">
  <p class="text-xl font-extrabold leading-snug">Extrabold heading</p>
  <p class="mt-5 text-base font-semibold leading-snug">Semibold, nested under it</p>
  <p class="mt-2 text-sm leading-relaxed">
    Body copy sits at the normal weight. The jump from semibold to extrabold
    is doing the work of a size change, which is what lets headings stay close
    in size without collapsing into each other.
  </p>
</Card>

## Leading

Leading is set with the relative values, never a fixed pixel height. Four are
in use: `relaxed`, `snug`, `tight`, and `none`.

Body copy that runs to more than one line gets `leading-relaxed`. Headings
get `none` or `snug`, tightening as they grow — a 5xl stat wants `none`, a
`sm` sidebar heading wants `snug`.
