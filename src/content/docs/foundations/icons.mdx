Icons come from Font Awesome Pro. Most are solid. A few are regular, like the star, where an outline carries different meaning from solid.

An icon is an `<i>` tag carrying two classes, the variant and the name.

```html
<i class="fa-solid fa-trash"></i>
```

Use three styles. Solid is the default. Regular is for the few outlines. Brands is for a third-party logo like `fa-shopify`. Light, thin, duotone, and sharp stay unused so icons keep one weight across the product.

```html
<i class="fa-brands fa-shopify"></i>
```

Size and color come from Tailwind utilities rather than Font Awesome's own `fa-lg` and `fa-2x`, so an icon moves on the same scale as the text beside it.

```html
<i class="fa-solid fa-trash text-sm text-slate-700"></i>
```
