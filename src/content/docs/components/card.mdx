## Examples

### Surface

Content is passed as children, and the `surface`
prop sets the background: `default`, `glass`, `glassRaised`, `layered`,
`sunken`, or `dark`.

<div class="not-prose space-y-8">
  <Card>
    <h4 class="font-extrabold capitalize">Default</h4>
    <p class="leading-snug"> Most things use this white background for panels. Callouts, stats, dashboards panels, list rows, etc.</p>
  </Card>
  <Card surface="glass">
    <h4 class="font-extrabold capitalize">glass</h4>
    <p class="leading-snug">Use this for content panels like settings, forms, or sidebars. It allows inputs to subtly standout from the background and lets us put a white highlight border on the panel.</p>
  </Card>
  <Card surface="glassRaised">
    <h4 class="font-extrabold capitalize">glass raised</h4>
    <p class="leading-snug">Used for floating elements like sticky button containers or in page navigation where the blur effect can shine as layered elements slide below it. Only use on elements sitting on the page background, never nested inside other panels. This is because the panel transparency and color has been tuned to match the base surface glass color when mixed with the page background color.</p>
  </Card>
  <Card surface="layered">
    <h4 class="font-extrabold capitalize">layered</h4>
    <p class="leading-snug">Surface Base, Glass Raised, and solid color layers stacked at 20 pixel increments. Used only for marketing style callouts on a dashboard, hero, or similar area. Used very sparingly.</p>
  </Card>
  <Card surface="sunken">
    <h4 class="font-extrabold capitalize">sunken</h4>
    <p class="leading-snug">Use for sidebars or collapsible containers.</p>
  </Card>
  <Card surface="dark">
    <h4 class="font-extrabold capitalize">dark</h4>
    <p class="leading-snug">Only used for the app navigation bar.</p>
  </Card>
</div>

### Padding

The `padding` prop controls padding: `none` (no padding), `compact` (p-4),
`default` (p-6), or `spacious` (p-8). Use `none` when the card wraps content
that manages its own spacing, such as a table or an image.

<div class="not-prose space-y-8">
  <Card padding="none">none</Card>
  <Card padding="compact">
    <h4 class="font-extrabold capitalize">compact</h4>
    <p class="leading-snug">Used for sidebars, row items, or dense UI like a message inbox.</p>
  </Card>
  <Card>
  <h4 class="font-extrabold capitalize">default</h4>
    <p class="leading-snug">Used almost everywhere. Dashboard cards, analytics cards, form and settings cards.</p>
  </Card>
  <Card padding="spacious">
  <h4 class="font-extrabold capitalize">spacious</h4>
    <p class="leading-snug">Used for focused step by step flows like quick blast or modal content. Anything where the main UI is faded back or we have very low information density. Less stuff gives us more breathing room.</p>
  </Card>
</div>
