The Voxie logo has a rounded body, a white symbol, and a speech-bubble tail. The body keeps a 35:32 aspect ratio when sized by one dimension. The symbol and tail scale with it.

```vue
import Logo from '@ui/Logo.vue';

<Logo />
```

## Examples

### Size and radius playground

Choose width or height to resize the mark. Select **Fixed** under **Radius mode** to keep the corners at a specific radius while the size changes. The comparison row uses the same radius setting at several widths.

<LogoPlayground client:load />

### Sizing

The default body is 35px wide and 32px tall. Set one CSS dimension and leave the other on `auto` to preserve its proportions. Width and height are controlled through CSS, with no dedicated props.

<Card>
  <div class="not-prose flex flex-wrap items-center gap-8">
    <Logo class="w-6 h-auto" />
    <Logo />
    <Logo class="h-10 w-auto" />
    <Logo class="w-20 h-auto" />
  </div>
</Card>

```vue
<Logo class="w-6 h-auto" />
<Logo />
<Logo class="h-10 w-auto" />
<Logo class="w-20 h-auto" />
```

The tail extends below the body by one eighth of its height. An ancestor with `overflow: hidden` can clip it.

### Corner radius

The logo has a default radius that scales proportionally so it stays consistent across mixed uses. It is also designed to have it's radius match surrounding elements in UI. For example, if the Logo sits next to a button like it does in the navbar, we can set its radius to exactly match the button for a more cohesive design.

<Card>
  <div class="not-prose flex flex-wrap items-end gap-8">
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20" />
      <span class="text-xs text-slate-500">Proportional</span>
    </div>
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20" radius={8} />
      <span class="text-xs text-slate-500">8px</span>
    </div>
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20" radius={0} />
      <span class="text-xs text-slate-500">0px</span>
    </div>
  </div>
</Card>

```vue
<Logo class="w-20" />
<Logo class="w-20" :radius="8" />
<Logo class="w-20" :radius="0" />
```

A fixed radius stays the same as the mark changes size. The browser limits large radii to fit the body. The tail keeps its relative position when the radius changes.

## Props

| Prop | Type | Default | Behavior |
| --- | --- | --- | --- |
| `radius` | `number` or numeric `string` | Proportional | Sets the body’s corner radius in CSS pixels. Omit it to scale the corners with the mark. |

Classes and styles apply to the body. Pass numeric radius values such as `8` or `"8"`; the component adds the `px` unit.

## Accessibility

The mark is decorative and hidden from assistive technology. Give a link containing only the mark an accessible name. A link with visible text can use that text as its name.

```vue
<a href="/" aria-label="Voxie home">
  <Logo class="w-8" />
</a>
```
