The Voxie logo has a rounded body, a white symbol, and a speech-bubble tail. The body keeps a 34:32 aspect ratio when sized by one dimension. The symbol and tail scale with it. The `type` prop adds the Voxie word mark beside it.

```vue
import Logo from '@ui/Logo.vue';

<Logo />
```

## Examples

### Type

The `type` prop sets which parts render. The choices are `mark` (the default), `full`, and `word-mark`. `full` puts the word mark to the right of the mark, centered on the body. `word-mark` renders the letters alone.

<Card>
  <div class="not-prose flex flex-col items-start gap-8">
    <Logo />
    <Logo type="full" />
    <Logo type="word-mark" />
  </div>
</Card>

```vue
<Logo />
<Logo type="full" />
<Logo type="word-mark" />
```

### Appearance

The `appearance` prop sets the word mark's ink. `dark` (the default) is slate-900 for a light background. `light` is white for a dark one. The mark keeps its own color.

<div class="not-prose space-y-4">
  <Card>
    <Logo type="full" />
  </Card>
  <Card surface="dark">
    <Logo type="full" appearance="light" />
  </Card>
</div>

```vue
<Logo type="full" />
<Logo type="full" appearance="light" />
```

### Size and radius playground

Choose width or height to resize the mark. Select **Tailwind** under **Radius mode** to step through the `rounded-*` scale and keep the corners at that radius while the size changes. The comparison row uses the same radius setting at several widths.

### Sizing

The default body is 34px wide and 32px tall. Set one CSS dimension and leave the other on `auto` to preserve its proportions. Width and height are controlled through CSS, with no dedicated props. The same applies to `full` and `word-mark`, where the dimension you set is the whole logo's. At its default size `full` is 126px wide and 32px tall.

<Card>
  <div class="not-prose flex flex-wrap items-center gap-8">
    <Logo class="w-6 h-auto" />
    <Logo />
    <Logo class="h-10 w-auto" />
    <Logo class="w-20 h-auto" />
  </div>
</Card>

```vue
<Logo class="w-6 h-auto" />
<Logo />
<Logo class="h-10 w-auto" />
<Logo class="w-20 h-auto" />
```

The tail extends below the body by one eighth of its height. An ancestor with `overflow: hidden` can clip it.

### Corner radius

The logo has a default radius that scales proportionally so it stays consistent across mixed uses. It is also designed to have its radius match surrounding elements in UI. For example, if the Logo sits next to a button like it does in the navbar, we can set its radius to exactly match the button for a more cohesive design. A Tailwind `rounded-*` class overrides the default, so the logo can use the same radius token as the button beside it.

<Card>
  <div class="not-prose flex flex-wrap items-end gap-8">
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20" />
      <span class="text-xs text-slate-500">Proportional</span>
    </div>
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20 rounded-xl" />
      <span class="text-xs text-slate-500">rounded-xl</span>
    </div>
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20 rounded-md" />
      <span class="text-xs text-slate-500">rounded-md</span>
    </div>
    <div class="grid justify-items-center gap-5">
      <Logo class="w-20 rounded-none" />
      <span class="text-xs text-slate-500">rounded-none</span>
    </div>
  </div>
</Card>

```vue
<Logo class="w-20" />
<Logo class="w-20 rounded-xl" />
<Logo class="w-20 rounded-md" />
<Logo class="w-20 rounded-none" />
```

A class radius stays the same as the mark changes size. Use an arbitrary value such as `rounded-[7px]` for a size outside the scale. The browser limits large radii to fit the body. The tail keeps its relative position when the radius changes.

### Color

The body and tail default to sky-500. Text color classes change both. The symbol stays white. The word mark's color comes from `appearance`, so a text color class leaves it alone.

    <Logo class="text-slate-800" />
  </div>
</Card>

```vue
<Logo />
<Logo class="text-sky-600" />
<Logo class="text-slate-800" />
```

## Props

| Prop | Values | Default |
| --- | --- | --- |
| `type` | `mark`, `full`, `word-mark` | `mark` |
| `appearance` | `dark`, `light` | `dark` |

Classes and styles apply to the logo. Size it with a width or height class and shape the body with a `rounded-*` class.

## Accessibility

The mark is decorative and hidden from assistive technology. Give a link containing only the mark an accessible name. A link with visible text can use that text as its name.

```vue
<a href="/" aria-label="Voxie home">
  <Logo class="w-8" />
</a>
```
