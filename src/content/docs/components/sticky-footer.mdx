A sticky footer is the floating panel that holds a form's buttons. It stays 32px above the bottom of the window while the form scrolls under it, so the buttons are in reach at any point in the form. Write it last, in the same column as the cards it follows.

```vue
<PageLayout layout="create" title="New Contact">
  <Card surface="glass" class="w-full md:max-w-2xl">…</Card>
  <Card surface="glass" class="w-full md:max-w-2xl">…</Card>

  <StickyFooter class="md:max-w-2xl">
    <Button size="lg">Cancel</Button>
    <Button size="lg" color="sky" block>Save Contact</Button>
  </StickyFooter>
</PageLayout>
```

It takes no props. The default slot holds the buttons.

## Examples

### Sticking

While the end of the form is below the window, the footer floats 32px above the window's bottom edge and the cards slide under it. Once the end of the form scrolls into view, the footer rests in place under the last card. Scroll the box to see both.

</div>

The footer only travels inside its parent. Put it straight in the column that holds the form's cards, as the last child. Wrapped in an element of its own, it has no room to travel and stays where it was written.

It sticks to the nearest ancestor that scrolls, which is normally the window. An ancestor with `overflow-hidden` counts as that ancestor even though it never scrolls, so a footer inside one stops floating.

### Surface

The panel is the `glassRaised` surface from [Card](/docs/components/card#surface), padded by 16px, then 24px from `sm`. It announces `glass` to everything inside it, so a slate [Button](/docs/components/button#surface) comes out slate-200 without being passed `sitsOn`. Like every glass raised panel, it goes on the page background only, never inside another panel.

### Buttons

The slot is a row with an 8px gap. The buttons in it follow the [two buttons](/docs/components/button#two-buttons) rule. The primary action is written last with `block` and fills the row. The secondary button sits on the left at its own width.

### Width

The footer fills the width of its parent. Give it the width class of the cards above it, so its edges line up with theirs. On a [create page](/docs/patterns/page-structure#create-pages), and for the small cards on a [sidebar page](/docs/patterns/page-structure#sidebar-pages), that is `md:max-w-2xl`.

### Resting place

At the end of the page the footer rests under the last card. [Page Layout](/docs/components/page-layout#bottom-space) leaves 24px below it, and 128px from `md`, so it settles above the bottom of the window instead of against it.

## Migration

This component replaces `vx-sticky-footer` from `@voxie/frontend-components`. It still takes no props, and the default slot carries over. The panel is now the `glassRaised` surface, so it is `bg-white/80` with `backdrop-blur-lg` where the old one was `bg-white/70` with `backdrop-blur-md`.
