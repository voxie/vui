Button documentation goes here. MDX pages can render live component examples:

Grayscale buttons go approximately a step from their background.

Surface Base (white) → button slate-100
Surface Glass (white/60) → button slate-200
Surface Sunken (slate-300/30) → button slate-300
Surface Dark (slate-700) → button slate-600

Background (slate-200) → button white
Background (slate-200) → button slate-300
Background (slate-200) → button slate-600

renders an `<a>` instead of a `<button>`.
