# Font Awesome Configuration

## Integration

- **Method:** Hosted Kit (`<script>` embed) — Web Fonts + CSS
- **Kit ID:** 06f511676f
- **Version:** 7.3.1
- **License:** Pro
- **Families:** classic, sharp, duotone, sharp-duotone, brands

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

The Kit script is loaded once in the `<head>` of `src/layouts/Layout.astro`, so
it is available on every page. There is nothing to import per component.

## Conventions

Icons are written as `<i>` tags with the Kit's web-font classes:

```html
<i class="fa-solid fa-cart-shopping"></i>
```

Use Tailwind utilities for sizing and color rather than Font Awesome's own
`fa-lg` / `fa-2x` helpers, so icons follow the same scale as the rest of the
system:

```html
<i class="fa-solid fa-cart-shopping text-sm text-slate-700"></i>
```

Icons that sit inside a `prose` region on the docs and skills templates should
be wrapped in `not-prose`, like the other live component examples.
