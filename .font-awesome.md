# Font Awesome Configuration

## Integration

- **Method:** Hosted Kit, loaded by a `<script>` in `<head>` of both layouts (`src/layouts/Layout.astro` and `src/layouts/TestPageLayout.astro`)
- **Kit ID:** ec399ebc2e
- **License:** Pro (commercial). The Pro CSS and fonts are never committed; the kit serves them, so the repo can be public.

The kit was self-hosted for a while for performance, but the Pro files can't live in a public repository, so it went back to the kit. Families and styles are configured on the kit at fontawesome.com, not in this repo.

## Defaults

- **Style:** solid
- **Family:** classic

## Conventions

Icons are written as `<i>` tags with the web-font classes:

```html
<i class="fa-solid fa-cart-shopping"></i>
```

Use Tailwind utilities for sizing and color rather than Font Awesome's own `fa-lg` / `fa-2x` helpers, so icons follow the same scale as the rest of the system:

```html
<i class="fa-solid fa-cart-shopping text-sm text-slate-700"></i>
```

Icons that sit inside a `prose` region on the docs and skills templates should be wrapped in `not-prose`, like the other live component examples.
