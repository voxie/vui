# Font Awesome Configuration

## Integration

- **Method:** Self-hosted web fonts + CSS, bundled by Vite
- **Version:** Pro 7.3.1
- **License:** Pro (commercial). `src/styles/fontawesome/LICENSE.txt` travels with the files. This repo is private, and the Pro fonts must not be committed to a public one.
- **Families present:** classic solid, classic regular
- **Kit ID (unused):** 06f511676f

The hosted Kit was replaced because it was a third-party script in `<head>` with `cache-control: max-age=60`. Every navigation blocked on a fresh round trip to `fontawesome.com`, which then chained four stylesheets and a font off `ka-p.fontawesome.com`. Self-hosted, the same icons cost one same-origin stylesheet and one font, both hashed and cached for a year.

## Files

```
src/styles/fontawesome/
  css/fontawesome.min.css   core: the icon class map and utilities (fa-fw, fa-spin, ...)
  css/solid.min.css         @font-face for classic solid
  css/regular.min.css       @font-face for classic regular
  webfonts/fa-solid-900.woff2
  webfonts/fa-regular-400.woff2
  LICENSE.txt
```

Both layouts (`src/layouts/Layout.astro` and `src/layouts/TestPageLayout.astro`) import the three stylesheets, so icons work on every page with nothing to import per component. Vite folds them into the site's single stylesheet and rewrites the font URLs to hashed assets. Solid is on every page, so each layout also preloads it.

## Adding a family

Only solid and regular are here. Writing `fa-brands`, `fa-light`, `fa-duotone`, or a sharp class renders nothing, silently. To add one, take its CSS and woff2 from the full Pro web package, keep the `css/` and `webfonts/` layout so the relative `url()` still resolves, and add the import to both layouts.

## Defaults

- **Style:** solid
- **Family:** classic

## Conventions

Icons are written as `<i>` tags with the web-font classes:

```html
<i class="fa-solid fa-cart-shopping"></i>
```

Use Tailwind utilities for sizing and color rather than Font Awesome's own `fa-lg` / `fa-2x` helpers, so icons follow the same scale as the rest of the system:

```html
<i class="fa-solid fa-cart-shopping text-sm text-slate-700"></i>
```

Icons that sit inside a `prose` region on the docs and skills templates should be wrapped in `not-prose`, like the other live component examples.
