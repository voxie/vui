Typography

Most of the type here is working type, the dense UI of an application rather than reading material. So the default is text-sm, not text-base. The scale goes down from there before it goes up. Reach for xs or 2xs when a surface needs to hold more.

Typeface

The typeface is Inter, a workhorse drawn for interfaces. It’s self-hosted as a variable font across the full 100–900 weight axis, so any weight costs the same as any other.

sm

text-sm14pxThe default. Body copy, and headings in a sidebar or aside.

xs

text-xs12pxDense UI, and the small end of aside headings.

2xs

text-2xs10pxThe floor. Small badges, and very dense UI like day labels in a calendar. Rarely reached for, and never a heading.

These are recommendations, not restrictions. Nothing in Tailwind is off the table. 2xl and 4xl are there when a layout needs them. They just don’t have a job of their own in the brand.

2xs is the exception. It isn’t a Tailwind size at all. It’s defined in global.css as a 10px rung below xs, with a 14px line height that matches the shape of the built-in sizes.

Headings in markup

Heading levels don’t map to fixed sizes. What a level is worth depends on where it sits. As a starting point:

ElementSize
h1 on the page background3xl
h1 inside a cardxl
h2xl
h3base

Responsive

Sizes step down below the xl breakpoint, and only at the top of the scale:

<h1 class="text-2xl xl:text-3xl">Page heading</h1>

Large body copy in a hero or marketing section drops a rung the same way, usually base to sm. Everything else holds its size at every width. It’s already dense and has nowhere to go.

Weight

Body copy is the normal weight. Headings are font-extrabold. Where headings nest and need separating, or where a heading should sit back rather than announce itself, drop to font-semibold.

Never all caps.

Extrabold heading

Semibold, nested under it

Body copy sits at the normal weight. The jump from semibold to extrabold is doing the work of a size change, which is what lets headings stay close in size without collapsing into each other.

Leading

Leading is set with the relative values, never a fixed pixel height. Four are in use.

ValueWhere
leading-relaxedBody copy running to more than one line
leading-snugMost headings, and the smaller end of the scale
leading-tightSelect inputs, badges, and similar compact controls
leading-noneThe largest headings and stat callouts

Headings tighten as they grow. A 5xl stat wants none, and a sm sidebar heading wants snug.

Body copy that runs to more than one line gets the loosest of the four, because the eye has to find its way back to the start of each line.

Tracking

Inter is drawn tight, which is right at text sizes and wrong at both ends of the scale. Small type opens up so it doesn’t clot. Display type closes up so it doesn’t drift apart.

Tracking is paired to the size tokens in global.css, so it arrives with the size class and there’s nothing to remember. text-3xl is already tracked. Tailwind’s own scale moves in 0.025em steps, which is too coarse across this range, so the values are graded:

SizeTracking
2xs0.015em
xs0.01em
sm base lgnone
xl-0.005em
2xl-0.01em
3xl-0.02em
4xl 5xl-0.03em

Adding a tracking-* utility still overrides the paired value, so text-3xl tracking-normal flattens that one heading.

Numerals

Numbers are set in tabular figures, applied on body so it holds everywhere. Every digit shares one width, so a column of numbers lines up and a live value doesn’t jitter as it changes.

Truncation

Dense lists need a hard ceiling on how much room a row can take. In a long list of rows, headings truncate to one line and body copy clamps to two:

A conversation subject long enough to need cutting off

The body preview clamps at two lines, so every row in the list is the same height no matter how much the sender wrote, and the list stays scannable all the way down.

Everywhere else, let text wrap, and wrap it well. text-balance on headings evens the line lengths so you don’t get one orphaned word. text-pretty on body copy does the lighter version of the same thing.

Measure

65 characters is a reasonable ceiling for a paragraph. There isn’t much long-form text in the product, so it rarely comes up. It’s the number to reach for when it does.

A note on controls

Buttons and other controls set their own type and sit a rung below body copy at their default size. That isn’t a contradiction. A control has weight, padding, and a fill separating it from everything around it, none of which body copy gets.
